Bridge

Version: 0.2.0

A local game library manager that unifies games from external libraries, manual entries, and emulated ROMs into one fast, self-contained catalog — no plugin runtime, no bloat.

Features

  • Steam and Epic library auto-import with local metadata and icons.
  • Launch games and track playtime — Steam via steam://rungameid, directory/process-tree tracking.
  • IGDB metadata with zero config (Bridge Cloudflare Worker) plus optional user IGDB credentials.
  • Managed RetroArch: scan ROM folders, download frontend/cores on first play.
  • Three view modes (List, Covers, Table) with search, filters, sorting, and grouping.
  • Statistics dashboard, screenshot gallery, self-updater, and dark WPF-UI theme.

Getting Started

Download the latest release from GitHub Releases, or build from source:

dotnet publish Bridge/Bridge.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

The database is created automatically on first launch under %LOCALAPPDATA%\Bridge\.
