Bridge

Version: 0.1.0

A local game library manager that unifies games from external libraries, manual entries, and emulated ROMs into one fast, self-contained catalog — no plugin runtime, no bloat.

Features

  • Manual game library: add, edit, delete, favorite/hidden flags, local SQLite persistence.
  • Launch games and track playtime automatically — Steam games launch via steam://rungameid with directory-based tracking, no per-game setup.
  • Automatic Steam library import on startup (registry → libraryfolders.vdf → appmanifest*.acf), deduped by (ExternalId, SourceId).
  • Metadata from IGDB and the Steam Store (auto-downloaded for imported Steam games), plus Steam client icons.
  • ROM folder scanning and emulator setup with {RomPath} substitution.
  • Three view modes (List, Covers, Details) with search, filter presets, sorting, and grouping.
  • Statistics dashboard (library counts, playtime, completion status, top played).
  • WPF-UI dark theme with Mica backdrop, sidebar navigation, and Inter variable font.

Getting Started

Build and run from the repo root:

dotnet build Bridge.slnx -c Release
dotnet run --project Bridge/Bridge.csproj

The database is created automatically on first launch under %LOCALAPPDATA%\Bridge\.
